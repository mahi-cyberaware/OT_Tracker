# WorkTrack V28.0.8 — Attendance Persistence & Mobile Month Controls

- Attendance saves now use Supabase `upsert` on the existing unique `user_id, work_date` key.
- The exact saved date is verified from the database before the form closes.
- Attendance loading reads the signed-in user’s attendance set and filters the selected month locally, preventing month-boundary records from being dropped by the date-range read.
- Dashboard, Calendar, Attendance History and Reports keep their existing selected-month behavior.
- Current/Previous/Next month controls remain on one horizontal row on mobile instead of wrapping.
- Existing Supabase/RLS policies are unchanged.
- Service-worker/app cache versions updated for V28.0.8.
