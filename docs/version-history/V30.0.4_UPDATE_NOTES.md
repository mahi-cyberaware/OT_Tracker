# WorkTrack V30.0.4 — Excel Download Compatibility Fix

## Summary
Improves roster Excel downloads on Android and other mobile browsers.

## Changes
- Generates XLSX bytes explicitly using SheetJS.
- Wraps the file in a Blob with the official Excel Open XML MIME type.
- Uses a month-specific `.xlsx` filename.
- Preserves the selected-month filtering introduced in V30.0.3.
- Adds a unique Update Center background and release slide.
- Keeps the latest six slides visible and preserves older slides in the archive.

## Safety
No roster data, attendance calculations, Supabase configuration, or RLS policies were changed.
