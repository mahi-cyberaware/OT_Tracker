# WorkTrack V27.1 — Statement + Profile Fixes

## Statement generation
- Base incidents now start with: `I was allocated for the <flight> base catering check.`
- Ramp incidents now start with: `I was allocated for the <flight> handling on the RAMP.`
- Other locations use a neutral location-specific opening without inventing facts.
- OCR is treated as the report/questioning/complaint.
- Employee explanation is treated as the factual answer to the OCR points.
- AI providers are instructed to generate only the answer body; the application adds the mandatory opening and `Dear Sir,` consistently.
- Built-in fallback uses the same opening logic, so the output remains operational when all external AI providers fail.

## Profile
- Fixed profile dialog close and cancel controls.
- Hardened profile avatar rendering in the top-right header avatar.
- Profile picture remains private through the existing Supabase Storage signed-URL flow.

## Deployment
- This is a V27 branch update. Do not merge to `main` until testing is complete.
- Existing Supabase `profile-avatars` bucket/policies do not need to be recreated if already installed.
