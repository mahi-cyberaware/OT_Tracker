# WorkTrack V30.0.3 — Monthly Roster Downloads

## Summary
Roster exports now use the month currently selected in the My Roster view.

## Changes
- Added clearly labelled Previous month, Current month, and Next month controls.
- PDF download includes only entries from the selected month.
- Excel download includes only entries from the selected month.
- Export filenames include the selected `YYYY-MM` month.
- Empty months show a clear message instead of exporting all months.
- Kept roster data, duty timings, and existing display behavior unchanged.
- Added a unique Update Center background and release slide.
- Kept the latest six Update Center slides visible and preserved older slides in the archive.

## Safety
No attendance calculations, Supabase configuration, RLS policies, or roster records were changed.
