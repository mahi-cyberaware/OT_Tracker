# WorkTrack V28.0.6 — Dashboard Historical Month Navigation

## Changes
- Added a dedicated Dashboard month selector.
- Added Current month, Previous month and Next month controls directly above Dashboard statistics.
- Dashboard statistics now visibly identify the selected month.
- Existing Calendar, Attendance History, Analytics and Reports remain synchronized through the shared selected-month state.
- No Supabase schema, RLS policy or SQL changes.
- Service-worker cache version advanced to V28.0.6.

## Attendance example
A record saved for 30 September 2026 can be reviewed by selecting **Previous month** from the Dashboard while the current month is October 2026.
