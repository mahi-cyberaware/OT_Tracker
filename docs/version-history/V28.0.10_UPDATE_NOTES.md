# WorkTrack V28.0.10 — Attendance Date & Editing Fix

Date: 12 October 2026

## Changes
- Fixed month-end date calculation to avoid `toISOString()` shifting the local calendar date to the previous day in UTC+ time zones. This directly addresses records on the last day of a month being excluded by the selected-month filter.
- Added an editable Break minutes field to the attendance form.
- Editing an existing attendance record now updates by its row ID and signed-in user instead of upserting under a changed date.
- When changing a work date, the app checks for another record for the same user/date and prevents accidental duplicates.
- Preserves overtime reason, notes, status, check-in and check-out editing.
- Added V28.0.10 to the Update Center.

## Testing status
This is a test build. JavaScript syntax and package contents should be checked before deployment; the user must verify the attendance row persists and displays after refresh in the test branch.

## Database / security
No schema, SQL migration, or RLS changes are included.
