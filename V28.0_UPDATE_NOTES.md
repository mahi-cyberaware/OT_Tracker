# WorkTrack V28.0 — Attendance Duplicate-Date Protection

## Purpose
Fix attendance entry when the database already contains a record for the same user and work date.

## Changes
- Attendance loading is explicitly scoped to the signed-in user.
- Adding attendance checks the exact `user_id + work_date` pair before inserting.
- If a record already exists, the app opens that existing record for editing instead of creating a duplicate.
- Database unique-constraint race conditions are handled gracefully.
- Editing an attendance record prevents changing its date to one already used by another record.
- Raw Supabase duplicate-key errors are no longer shown for this scenario.
- Existing attendance calculations, overtime rules and the database unique constraint remain intact.
- Update Center includes the V28.0 release slide.
