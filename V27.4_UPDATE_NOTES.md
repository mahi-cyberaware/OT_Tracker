# WorkTrack V27.4 — Roster & Account Contact Upgrade

## Roster
- The employee roster now opens on the current month by default.
- Other months are no longer mixed into one long list.
- Added Previous, Next and Current Month controls.
- Next Month is enabled only when roster data exists for that month.
- Tomorrow's duty/reminder logic still uses the complete private roster dataset.

## Account contact settings
- Implemented the Save email & mobile action.
- Email changes use Supabase Auth `updateUser` with the production redirect URL.
- Added confirmation status messaging and refresh of the authenticated user after updates.
- Mobile number is stored in the signed-in user's metadata.
- Existing authentication/profile behavior is preserved.

## Cache
- Updated application and service-worker versions to V27.4.
