# WorkTrack V28.0.5 — Attendance Read Scope & Dashboard Month Navigation

- Attendance loading now explicitly filters by the signed-in `user.id`.
- Preserves the existing unique `(user_id, work_date)` database constraint and RLS setup.
- Dashboard month navigation now clearly provides **Current month**, **Previous month**, and **Next month** controls.
- Dashboard statistics continue to represent the selected month; previous-month data can be viewed without changing stored records.
- Cache/service-worker version updated to prevent an older V28 JavaScript shell from being reused.
- Update Center includes the V28.0.5 release entry.
